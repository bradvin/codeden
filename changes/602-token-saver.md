- **Token saver.** Settings → General → Token saver adds a short note to each session's system prompt that asks for terse answers, the least code and narrow searches, at Lite, Full or Ultra (off by default). Exact technical terms and the words not, never, no and only are kept, and security warnings, irreversible steps and text that leaves the session stay in full sentences. Each role can have its own default, and a project can override it in its settings. It never relaxes CodeDen's own rules for a role, permissions or security. Sessions on providers whose system prompt holds for the whole conversation (Claude Code and Codex) get it, whoever started them: you, project managers, the orchestrator, the factory or automations. It applies to sessions started or resumed after a change. (#602)
