- **The agent CLIs and the GitHub CLI are found in the package managers' global folders.** On macOS and Linux, Claude Code, Codex, OpenCode, Gemini CLI and `gh` installed with Bun, pnpm, Volta or npm's own prefix, or in `~/.local/bin` or Homebrew, are found even when those folders are not on CodeDen's PATH.
